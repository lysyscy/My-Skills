# 分诊标签

Matt 工程技能使用下表将分诊角色映射到本地票的 `Status:`。

| 角色 | 本地 `Status:` | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待分诊 |
| `needs-info` | `needs-info` | 待补信息 |
| `ready-for-agent` | `ready-for-agent` | 可交给代理 |
| `ready-for-human` | `ready-for-human` | 需人工处理 |
| `wontfix` | `wontfix` | 不处理 |
