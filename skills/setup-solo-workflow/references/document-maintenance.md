# 日常文档维护

本文件是个人方法中日常文档维护的唯一正文。仅在本次确实修改文档或发现现行资料受影响时读取；不因此启动全仓治理。首次选择资料落点读 [document-layout.md](document-layout.md)，专项迁移读 [document-migration.md](document-migration.md)。

## 唯一事实与最小影响

先找到本次涉及事实的现行权威；业务定义、术语、架构、决策、操作方式各归各位。任务规格/票只记录本次差异、验收引用、状态和下一步，不复制整份现行业务。

只更新被本次改动弄过时的正文、指针和实际消费者。无文档影响不造日期改动、重复摘要、空目录、空 ADR 或空台账。派生文件按实际生成关系维护，不用人工双写冒充一致。

## 内容组织

稳定且常读的目的、边界、长期规则和导航靠前；概念的必要限制与例外跟概念放一起。动态环境/运行事实从稳定入口分开，操作前读取对应真实来源。

当前状态页把当前结论置顶；安全限制必须在相应危险动作前可见。普通任务先限定现行资料和当前 effort；核历史是否保留时使用差异或摘要，不预读无关历史正文。只有明确追溯、需要判定引用冲突或原裁定影响当次范围时，才读取有关历史。低频历史退出日常正文与默认搜索，并保留必要来源供追溯。

## 引用和保存边界

新增引用必须指向实际存在且当前有效的主人；分段引用要能定位必要正文。修改/移动影响机器消费者时核真实路径、扫描范围和配置，不能只检查 Markdown 链接。

实现者同步自己改动影响的现行资料，主 Agent 合并公共入口和状态。只记录真实完成程度：实施、验证、人工验收、部署和归档不是同一件事。

不在本文件再启动测试、独立审查、提交、推送或包同步；这些由当前任务唯一执行主人按已获授权处理。本文件只说明文档影响及其必要证据。

保护活动任务、他人修改、未提交原件及独有来源。删除/批量迁移不属于日常维护，转入专项清单；不因资料较旧或放在 scratch 就当可丢弃。

## 目录与规则职责

新落点的唯一目录契约见 [document-layout.md](document-layout.md)；批量迁移与恢复见 [document-migration.md](document-migration.md)。此旧锚点只作兼容指针。
