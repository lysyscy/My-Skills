# 日常文档维护

本文件是个人方法中日常文档维护的唯一正文。仅在本次确实修改文档或发现现行资料受影响时读取；不因此启动全仓治理。创建或变更资料落点、受管理产物，或归属/生命周期不清时读 [document-layout.md](document-layout.md)，专项迁移读 [document-migration.md](document-migration.md)。

创建或修改 Agent 消费的文档前，定位并读取实际安装的 writing-for-agents，应用其指针、步骤和完成判据方法；项目约束决定本仓的实际布局、权限与验收。只消费本次相关参考，不因此启动技能维护。

## 唯一事实与最小影响

先确认资料供谁在什么动作中读取，再找本次涉及事实的现行权威；业务定义、术语、架构、决策、操作方式各归各位。优先复用已有主人；确有独立读者或触发时可以新建文档，不强制每份资料增加元数据或行数指标。任务规格/票只记录本次差异、验收引用、状态和下一步，不复制整份现行业务。

区分长期规范、当前事实、待裁定建议、任务状态和历史证据。新增或加强长期规范前，向用户呈现具体条文、适用范围、被替代内容及新增负担，取得明确批准；审计建议、单次缺陷或临时规避不能自行升级为长期规则，脚本和测试同样适用。准确转录、迁移、去重或纠正已批准规则无需重复审批；削弱既有保护按原授权处理。

只更新被本次改动弄过时的正文、指针和实际消费者。无文档影响不造日期改动、重复摘要、空目录、空 ADR 或空台账。派生文件按实际生成关系维护，不用人工双写冒充一致。

## 审计与职责收敛

怀疑文档重复或失效时，先运行已有机械检查，再盘点实际文件（含未跟踪资料），按职责、真实读取者与触发分类。核一事多处、职责混杂、过期事实、无消费者或死链、缺少必要主人，以及历史记录误当现行规则；篇幅仅帮助定位，不是删除阈值。

业务定义、工作方法、项目操作、配置、编号归属、当前状态和历史证据各有唯一主人。覆盖表只登记编号到负责规格/票的关系，不复制业务条文或部署流水；状态页只导航活动范围、阻塞和必要恢复入口。通用方法归个人技能，项目只保存实际路径、命令入口、协议和必要例外。

只读审计止于建议；已有明确实施授权时完成范围内合并、删除、归档及消费者修正，无需为同一动作再次确认。历史去向按 document-layout.md，迁移前后核独有信息、引用与实际消费者，再运行受影响检查。没有机器检查能证明语义无冲突，仍须核实际职责与独有信息是否丢失。

## 内容组织

稳定、重要的目的、边界、长期规则和导航靠前；经常变化且次要的运行细节、过程和低频参考靠后或移到按需资料。概念的必要限制与例外跟概念放一起。动态环境/运行事实从稳定入口分开，操作前读取对应真实来源；PID、schema、构建与服务状态归实际运行主人，其他文档引用该来源。历史快照须表明当时版本和边界，不把旧通过数当当前验证。

当前状态页把当前结论置顶；安全限制必须在相应危险动作前可见。普通任务先限定现行资料和当前 effort；核历史是否保留时使用差异或摘要，不预读无关历史正文。只有明确追溯、需要判定引用冲突或原裁定影响当次范围时，才读取有关历史。低频历史退出日常正文与默认搜索，并保留必要来源供追溯。

## 引用和保存边界

新增引用必须指向实际存在且当前有效的主人；分段引用要能定位必要正文。修改/移动影响机器消费者时核真实路径、扫描范围和配置，不能只检查 Markdown 链接。

实现者同步自己改动影响的现行资料，主 Agent 合并公共入口和状态。只记录真实完成程度：实施、验证、人工验收、部署和归档不是同一件事。

交付前逐项核本轮文档的 writing-for-agents 应用、项目约束、层级、引用和结束材料去向；资料落点与生命周期按 document-layout.md，由 execution 唯一收尾核实际消费者、退出无用途的本任务资源，并执行已触发的相关检查；未满足的项回唯一收尾处理。当前状态页和操作前必要安全限制保留前置，不按修改频率机械后移。

不在本文件再启动测试、独立审查、提交、推送或包同步；这些由当前任务唯一执行主人按已获授权处理。本文件只说明文档影响及其必要证据。

保护活动任务、他人修改、未提交原件及独有来源。已授权改动及阶段收尾包含直接相关资料的合并、删除、引用修复；父任务仍活动不阻止已失效文件或段落退出。跨任务、归属不明或改变长期资料结构的批量治理转专项清单；不因资料较旧或放在 scratch 就当可丢弃。
