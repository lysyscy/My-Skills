# 项目记忆接入与内容迁移

仅在新建/初始化、明确接入共享记忆或获批专项迁移时执行。共同职责、检索和留存边界归同技能 [统一自定义指令](agent-instructions.md)；日常任务直接消费已接入口，不重复本流程。

## 定位与绑定

1. 核实际使用端的自定义指令、可调用接口、个人方法消费版本和项目正式入口。宿主部署一次，多项目复用；配置存在不等于调用成功。
2. 确认逻辑项目和实际工作分支。复用现有 bank 绑定；同项目多工作树共库，必要的稳定 bank ID 放既有项目入口/workflow，分支条件随记录保存。无明确项目只用个人库，不按客户端默认 cwd 建库。
3. 新项目只建立必要指针和项目事实，无历史不做迁移，不创建空库、票、status 或 ADR。已有项目首次完整接入进入下节；仅检查连通性或修复入口时保持该窄范围。
4. 复用有效端侧证据，核当前端实际读取共同正文并调用正确 bank。服务不可用可完成独立绑定，内容迁移和来源退出仍保持未完成。

## 已有资料的一次筛选

读取已授权的当前 Agent 入口、直接相关现行正文和项目自有技能；完整语义不足时定向补读，不导入全部历史。

| 内容职责 | 处理 |
|---|---|
| 现行规则、验收、边界、操作方法、仍影响维护的关键理由 | 保留正式主人；明确重复可合并并修引用 |
| 明确长期偏好、决定背景、经验证经验，且不是唯一规则或任务状态 | 按共同政策形成有条件、有来源的记忆 |
| 无独有价值的重复或已无用途的流水 | 按既有生命周期退出，不为迁移数量入库 |
| 降级会改变规则含义、冲突或确认状态不明 | 保持原文及效力，集中提交具体裁定；继续独立项 |

在当前任务记录对应来源段落、实际原文恢复点、分类理由、目标库和记录标识、验证及来源处置。恢复点必须包括实际 dirty/非 Git 原文，不能只指向缺少新内容的 HEAD。

先用本轮合成内容验证实际接口的查重、持久化、更正与分库，复用仍有效证据。再提炼真实候选，保留否定、例外、来源、日期、分支及计划/验证状态。查重后写入，核完成状态、实际提取内容，并换一个接近未来任务的问法召回。未知结果先查询，不盲目重写。

仅在知识正确持久化、实际原文可恢复、当前消费者已处理后精简来源。正式约定及关键理由仍保留，修复受影响引用。无可靠撤销或语义核验失败时停止相关写入/来源退出，保留原文；无候选可报告真实迁移 0 条。

## 验收、重跑与保存

验收相关入口与真实调用、项目/工作树身份、无项目、空库/不可用、旧记忆冲突、只读/禁止记忆、重复运行及更正；普通业务与开发分别走其原入口。用隔离新项目和已有项目样例核两条接入路径；相同输入重跑不重复导入、不新增空材料、不重写无变化正文。修改机制时回 [接入验证](setup-evaluation.md)，无产品改动不运行无关产品测试。

完成范围和依据版本留现有记录。以后只处理新增缺口、受影响资料或明确要求的新范围；曾完成不等于忽略新授权。区分源修改、提交、分发、端侧加载、调用和持久化。某端不可操作时交付准确待应用正文及剩余步骤，不报全部完成。

回滚只恢复本轮文件/配置差异，保护后续无关修改；只处理本轮可定位的记忆，不恢复全库。工作分支修改随正常合并进入主线，核受影响指针与记录范围，不在主线重新执行整批迁移；合并不证明部署。
