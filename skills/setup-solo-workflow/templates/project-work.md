# 项目工作规则模板

接入时将以下内容合并到现有主人，替换所有占位符；此文件不是日常任务入口。

- 项目入口按动作指出业务、架构、验证与发布正文，不要求每次通读全部资料。
- 普通实施：确认需求与已有修改，完成实现、相关验证、文档同步和授权收尾；只读任务止于结论。复杂统筹或专项技能按实际触发采用。
- 业务权威：[项目要求入口]；代码约束：[项目规范入口]。真实金额、归属、权限及接口含义以其为准。
- 检查命令：[项目实际安装/单测/静态检查命令]。按风险选测，已有有效证据复用。未执行、失败、超时不报通过；不删除有效保障或改变预期换绿灯。
- 审查按后果选自查或独立审查；累计范围包含本任务未提交/新增内容，排除他人工作。
- 保存与发布：[项目实际授权与Git/CI约定]。源码提交、服务加载、外部写入及业务验收分别确认并报告。
- 有关隔离、预览和资源退出的适用规则直接引用项目已部署的专题，不引用 setup 的模板或 implement 的旧执行手册。
- 采用来源：[模板来源与固定版本]；项目适配直接留在各自正文。活动任务基线不因模板更新自动变化。
