# 数据验证模块

仅部署到有此风险的项目，并填入实际测试入口与数据目标。

- 会写入的检查先确认实际数据库/文件目标、账号会话、输出与清理归属。浏览器隔离不能代替后端隔离；正式服务与业务写入按独立授权。
- 使用已核专用副本或隔离夹具，核源码、构建和数据对应本次输入；复制失败或版本不符时停止依赖检查，不改用正式库或不含待测行为的旧版本。
- 金额、权限、正常保存与必要撤销、归属和导出内容不丢不乱必须有有效保障；预期来自独立业务含义，不用同一实现重算证明自身。
- 共享机制变更核实际受影响入口；按真实失败模式覆盖事务、重试、并发或恢复，不能把单入口通过报为全部已核，也不机械跑所有组合。
- 区分产品、测试与环境失败；保留实际退出码和必要输入。退役行为可退出旧检查，但仍有效的保护不能以skip、放宽断言或换口径消除。
- 项目实际入口：[隔离准备命令、数据库身份核验、必要测试、收尾命令]。
