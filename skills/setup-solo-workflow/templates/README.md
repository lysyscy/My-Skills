# 布置模块

模板只在接入/更新时读取。生成内容进入现有项目或宿主入口，并记录采用来源与版本；日常任务不回读模板。

| 模板 | 目标与适用条件 |
|---|---|
| [宿主共同规则](host-instructions.md) | 宿主全局指令；包括无项目研究和技能触发的委派。保留现有宿主专用工具约定，避免重复注入。 |
| [项目工作规则](project-work.md) | 项目 AGENTS/CONTRIBUTING；按实际项目填写命令与主人。 |
| [数据验证](data-verification.md) | 涉及数据写入、金额、事务或恢复的项目验证指南。 |
| [预览](preview.md) | 有界面预览与人工验收入口的项目。 |
| [资源](resources.md) | 有临时运行、生成产物或共享资源的项目。 |

不要全部复制。先复用项目已有内容，缺什么补什么；未解析占位符不能成为有效部署。专项技能仍在各自安装包中，不随项目铺开一份技能手册。

更新采用三方比较：旧模板/新模板/项目现状。模板删除某段不意味着可以删除项目独有规则。首次缺旧基线时先核归属；无变化不改文件。自动检查只核可判定条件，不冒称已证明模型遵守文本。

无项目任务可将资源模块部署到宿主约定的按需入口；仅新增运行产物时消费。实际输出区与工具必须先接入，不使普通任务回读模板。
