# 运行资源模块

接入时沿项目实际消费者选择布局与命令；不凭目录名或年龄判定可删。

- 项目源表、业务原件、正式数据、在用构建、有效备份和他人未提交内容按各自生命周期保护。
- 活动任务 Markdown 与运行输出分开；一次性脚本与临时副本归运行work，可复用脚本归项目工具或所属技能维护源。
- 运行结束时核消费者、独有未保存状态和恢复用途；父任务未结束不妨碍已完成资源退出，回复结束也不取消用户验收用途。
- 必要证据只保最小集合，记录用途与到期日；具体期限按项目批准的规则。到期提示、运行结束清理和真正后台删除分别描述，未配置自动化不承诺离线动作。
- 清理先核真实绝对路径、链接边界及归属。源码历史可恢复不代表忽略文件或业务数据可恢复；数据库辅助记录须核实际业务依赖。
- 项目实际入口：[运行目录、生产者退出动作、归档期限与检查器、恢复依据]。未知归属或缺授权时保护现场并报告。
