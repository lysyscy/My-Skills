# 预览与界面验证模块

仅部署到有预览的项目，入口与具体操作由项目填实。

- 业务含义、重要内容取舍与使用流程由用户决定；已授权范围内可逆视觉细节由Agent实施并观察，不因每次构建创建审批点。
- 主预览供计划中的人工验收，记录实际加载版本、数据目标与负责人；用户仍需查看时保持用途，回复结束不等于退出。
- 临时预览由创建者负责，结论已保留、无活动消费者和独有状态后退出。停止服务与删除源码、数据库、工作树是不同动作。
- 修改前后实际操作受影响用户路径；截图不代替交互。瞬态跳动、闪动和回旧值要观察全过程并保留触发它的用户状态。
- 按影响选择代表数据量与视口，不默认全量浏览器矩阵；共享组件变化核受影响入口。技术检查、视觉确认、业务验收与部署分别报告。
- 项目实际入口：[预览启动、版本登记、隔离数据、停止与资源退出方式]。
