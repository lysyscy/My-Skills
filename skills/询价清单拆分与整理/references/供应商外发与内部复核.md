# 供应商外发与内部复核

在项目、地址确认后应用本规范。目标是每张分类表复制后即可单独询价；尾部保留原清单去向表，最后一张待办表管理未决事项，不能只隐藏内部列充当外发版。

## 先分信息，再确定合并键

| 内容 | 去向与处理 |
|---|---|
| 投标方采购安装、图纸外补充、来源文件/行号、合并及校验标记、无关的施工位置 | 仅内部复核表，不参与同料身份比较 |
| 介质、材质、规格、压力等级、制造标准、检测及证书、保温/防腐、法兰螺栓垫片、电控柜、配套附件 | 供应商表的规格、技术参数或备注，并参与合并判断 |
| 同一格同时含内部与供货要求 | 按片段拆开。例如删去“投标方采购安装”，保留同格“按规定试压探伤，需无损检测，出报告” |
| 业主自备、厂家范围、甲供等 | 属采购边界，不能当无用备注删掉后混合采购。列出实际行及数量让用户决定；未确认前不擅自当新增采购 |
| 图号、图集和待设备到货后核尺寸等 | 判断是否为供应商理解产品所需，保留必要技术依据；不把图集编号当材质牌号 |

“车间外侧管道需保温”“配套紧固件”“带表弯”会影响价格；不能与无此要求的同规格项直接合并。

## 同义比较的边界

按用户确认的严格程度，比较时可对齐空白、全半角、等义标点、乘号及明确的PN写法，显示值和内部原文分开保留。压力换算只作用于明确标为PN的公称压力；压力表量程、工况压力和型号中的数字不能按PN替换。

材质与参数的同义关系须核可信资料或明确源文，记录原写法、比较别名、依据及实际影响的组。可将Q235-B/Q235B这类明确写法对齐；Q235不能自动升级到Q235B，泛称不锈钢不能自动补成具体牌号，316与316L、铸件与锻件牌号及缺失材质保持独立。疑似拼写错误、未知代码、不同制造标准不可凭相似度替换。

完整参数参与分组。规格列搬到参数列之后不能遗漏参数；不同散热片数、功率、风量、接口长度、检测条件等仍是不同材料。身份核定为同料后才累加数量，原来源和各自数量保留内部。

## 成套与分项

检查合并的序号格、名称格、附/配套前缀、连续小项、相同原序号与图纸说明，建立可回溯的主项—附件关系。相邻或缺序号本身不足以证明所有行都是附件，要逐段实测确认。

用户选成套报价时：主项保留一个数量、单位和报价公式，附件名称、规格、材质、技术要求及原列有效数量写入主项参数；标明“附件数量为本项合计数量，含在成套价内，不另计价”。不推定未列的附件数量。不同主设备的附件不可脱离其主项跨设备累加；共享附件或嵌套子部件保留原关系。

长参数超出Excel行高显示上限时增加同项参数续行，续行不再填数量、单价和金额；打印抽查完整显示。合并名称对应的不同规格行仍是独立主项；共享参数按源中明确的合并关系承接并记录，不把22片与25片等不同规格合并。

未知代号、无数量的独立材料、整批汇总与已展开明细的交叉范围先展示事实，再由用户决定是否暂缓外发。内部保留完整原文，不删除源记录，也不把整批数量与明细当成可直接相加的同层级材料。

## 外发与内部工作表

- 供应商分表：默认10列，按[询价单模板规范](询价单模板规范.md)；仅保留报价必要字段与供货技术要求。没有来源、车间、校验说明、内部批注、隐藏的追溯列或跨表公式。必要材质、重量等信息放产品参数，不能因原列名像内部字段而丢弃。
- 内部复核（原清单去向表）：每条源记录保存原文件、原表、原行、全部原文、原数量/单位、去向、主项关系、合并成员、有效供货要求/内部说明的区分、待补项、别名依据及校验结论。表头明确提示只发送前面的分类表。
- 最后一张“待办”：先依据原清单处理能确定的事项，再将确实需要用户判断的事项按同一决策归组，附推荐。已完成的核对及已确认暂缓留内部复核，不占用户待办。具体字段与闭环见下一节。
- 每个分类只生成有数据的表，序号独立连续；空类别和额外列按用户已有决定，不重复询问。

## 原清单去向与待办分开保留

原清单去向表是全量证据，不因新增待办表而删除、替换或只保留问题行。保持每条源记录的唯一去向，供应商分类表在前、内部复核在后、待办最后。

### 先处理，再归组提交决定

1. 回读原行、同表描述、明确的主附件及汇总关系和已确认决定，先处理可证实的问题。记录原值、处理后值及依据；修正影响报价身份时复检重复组及数量，不把同表相邻就当成等义证据。
2. 将待处理事项分为：Agent可完成的核对、已确认处理但仍待补资料、需要用户作出的业务决定。前两类结论及剩余资料缺口留内部复核；只有第三类进入待办。资料缺失并不自动产生一个新用户决定，不让用户重复确认已批准的暂缓或成套报价。
3. 按能够一次回答的业务问题归组，如同一可疑材质写法或同一供货取舍；不同压力、材质及数量保持逐项记录。组内需要不同答案的列明子项，不借归组混合报价或掩盖差异。用户待办以组计数，明确另有多少源行受影响。
4. 每组列稳定编号、待决定问题、影响原行数、原清单证据、推荐、明确需用户回答的内容、文字定位、跳转、状态和决定填写栏。组内逐行索引放内部复核，保留原名称/规格/材质/数量/单位、源文件/表/行及对应报价项；用户无需先阅读全部来源行才能判断推荐。

用户选成套报价后，源内已确定主项的附件缺数量/单位，先按成套供货说明处理：原缺值不估填，要求供方列完整配置及数量并含在成套价内；共用部件保持原共用关系。只有存在互斥方案、必须由业主指定的配置或真实采购边界冲突时才提交用户决定。图集移列、非数值重量不参与计算、明确的汇总范围不重复采购等执行事项，按证据处理并留痕。

原描述与独立材质栏冲突时，核描述是否足以支持修正。例如同一行产品描述明确写某材质、独立栏只是异序拼写，按用户已授权的源文核定口径修正并保留两处原值；仅相邻产品写法相似或两个源字段均可疑的，保持原文并按同类问题归组请用户确认。

已确认暂缓外发但资料仍缺的在内部复核标明原决定及补资料条件，不再次加入待决定清单。用户给出结果后更新原组编号与状态，调整受影响报价及去向并复验数量；关闭记录保留追溯。

### 跳转与文字定位同时保留

跳转是复核与反馈入口，不能因某软件点不开就删除。使用真正的工作簿内部链接，明确目标工作表和单元格，例如openpyxl的`Hyperlink(ref=单元格, location="'内部复核'!A100")`；不要把`#'内部复核'!A100`作为外部文件target写入关系。目标表名正确引用，逐个验证目标存在。

提供“待办组→组内逐行索引→原清单去向/对应报价项→返回待办组”的路径；同一格长列表不能用一个链接冒充全部来源。每条同时写完整文件名、工作表名、原Excel行号及当前表行号，链接不可用时仍能查找。用户反馈故障时先确认Excel/WPS/预览环境，修实际链接；能取得目标应用时实测点击后的工作表及单元格，无法实测则明确验证边界，不宣称兼容已确认。

冻结位置依据实际表头：内部复核和待办第1行标题、第2行说明、第3行字段，冻结A4，只固定前三行；不把统计区、说明区或首批数据冻到第11行。补充统计放表尾或另经用户要求。供应商表按模板自身第2行表头冻结C3。检查打开文件的实际窗格、筛选范围、活动单元格及滚动位置，不只检查生成脚本。

## 独立验收

直接回读源文件和最终文件，按表头定位，不使用生成时的中间列表作为唯一真值。

1. 源记录集合与内部原文逐行一致；新增0、遗漏0，每行恰有一个去向。
2. 每个合并主项数量等于其源成员之和；单位一致，分单位核对，不混加米/吨/个。
3. 附件数量与原文出现在正确主项参数，且没有单独再次计价；暂缓项在内部完整保留。分别报告主项、附件、暂缓项，避免把不同层级相加来证明守恒。
4. 空白、仅空格和非数值数量分别检查。内部可显示“（空格）”，完整原行仍逐字保存。
5. 同义映射有正反例自检：同义可合；不同材质/规格/压力/片数/供货要求不合。所有合并成员能回到原行。
6. 报价表无内部信息与批注；保留混合说明中的有效检测/保温等要求；独立复制一张表试算并核无外部链接。
7. 所有公式真实重算并检查错误；抽查大标题、长参数、合计行、打印范围。源文件时间戳和指纹、上一交付版指纹保持不变。

8. 原清单去向表仍完整保留；源文可确定的先处理并留依据，已确认暂缓不重开，只有真实业务决定按组提交。组内来源齐全且数量不混合；跳转及返回目标正确，文字定位可独立查找。内部两表实际冻结前三行。
