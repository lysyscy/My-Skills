# 询价单模板规范

对外报价表应能独立发送，追溯信息在尾部内部复核表，未决事项及推荐在最后的待办表。表头和公式按本规范，不沿用历史案例11列断言。

## 大标题：先确认，后填入

每次先向用户确认本次项目全称与交货地址，当前消息明确提供即已确认；只出现在附件或历史中的值要作为候选请用户确认。确认前仅只读检查。商务条件固定“含13%增值税含运费，货到现汇付款”，本轮明确变更优先。

顶部A1:J1合并，宋体16号加粗、水平垂直居中、自动换行。标题格式：

```text
本次已确认项目全称
（含13%增值税含运费，货到现汇付款，地址：本次已确认交货地址）
```

不另加“材料计划”、技术实现说明或未确认商务条款。行高按标题实测调整，通常57—78磅，确保完整显示。附件仅作格式来源，旧项目名、地址和业务明细不进入通用空白模板。

## 供应商表

第2行10列表头：`序号｜材料名称｜规格型号｜材质/牌号｜技术参数｜单位｜数量｜备注｜单价｜金额`。

第3行起为报价项；本表序号1..N。成套附件在主项参数中，不再单列金额；长参数可续行但不重复数量和报价。供应商所需的检测、保温、配套、证书、标准和重量信息必须保留。内部来源、车间、合并标记、审计批注等只在内部复核表，不隐藏在报价表中。

| 项目 | 默认设置 |
|---|---|
| 字体 | 宋体；表头11—12号加粗、正文10—11号 |
| 列宽A:J | 6 / 29 / 28 / 20 / 55 / 8 / 12 / 35 / 13 / 16 |
| 单价I列 | 空白待填，淡蓝底，蓝字，`#,##0.00` |
| 金额J列 | `=IF(OR(In="",Gn="",NOT(ISNUMBER(Gn))),"",Gn*In)`；`#,##0.00` |
| 合计行 | A:I合并“合计”；J列`=IF(COUNT(J3:J末项)=0,"",SUM(J3:J末项))` |
| 视图 | 冻结C3；筛选表头至最后数据/参数续行，不包含说明区 |
| 打印 | 横向、按一页宽缩放；重复标题行1:2；只含本分类及有效供货要求 |

金额公式只引用本表；单独复制分类工作表仍可计算，无外部链接。不是将最后内部表隐藏后发送整个文件，而是发送对应分类表。

## 内部复核与待办

内容与数量核对见[供应商外发与内部复核](供应商外发与内部复核.md)。保留完整原清单去向表，另建最后一张待办表列问题、推荐及用户决定。内部两表默认第3行为表头、冻结A4，仅固定前三行；具体字段及闭环以该规范为准。内部复核保存项目地址确认、来源原文、数量去向、成套关系、合并成员、别名依据、缺项及本轮检查结论；不依赖供应商表中的隐藏列或批注。

## 空白模板及验证

`assets/询价单模板_空白.xlsx`只保留通用项目/地址占位、10列表头、空白格式行及合计公式，不含真实项目、地址、业务数据。交付业务工作簿前用已确认内容清零占位，不添加示例业务行。

验证表头逐字匹配、大标题格式与确认内容一致、序号连续、输入单价留空、金额与合计按当前10列正确引用；实际重算、独立分表试算和长参数打印抽查全部通过。跨工作簿复制真实font/fill/border/alignment对象，不搬_style索引。历史*_example.py需按本规范及表头名适配后使用。
