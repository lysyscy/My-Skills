# 询价单 / 材料计划表 模板规范

用户既有的询价单格式。新做询价单、材料计划表一律照此；**优先直接复用用户现有的同类文件作模板**（取其样式对象），只有拿不到才按下表重建。

来源样本：`D:\工作\材料\询价\中煤鄂尔多斯\…材料计划（管件）.xlsx`

## 结构

| 部位 | 规格 |
|---|---|
| 工作表名 | = 类别名（如 `管件`）；多文件形态时文件名 = `<项目名>（<类别>）.xlsx` |
| `A1:K1` 合并 | 标题 3 行（单元格内换行）：`项目名` / `材料计划` / `（含13%增值税含运费，货到付款，地址：…）` |
| 第 2 行 | 表头 11 列：`序号｜类别｜名称｜规格型号｜材质/牌号｜技术参数｜单位｜数量｜备注｜单价｜合价` |
| 第 3 行起 | 数据行，序号 1..N 连续（或沿用源序号） |
| 末行 | `A:H` 合并写「合计」，`K = SUM(K3:K{末-1})` |

## 视图与尺寸

| 项 | 值 |
|---|---|
| 冻结窗格 | `A3` |
| 自动筛选 | `A2:K{末行}`（**含合计行**） |
| 列宽 | A 6 / B 11 / C 26 / D 26 / E 22 / F 50 / G 7 / H 9 / I 16 / J 12 / K 14 |
| 行高 | R1 = 78、R2 = 30、数据行 = 33 |
| 默认行高/列宽 | `defaultRowHeight = 13.5`、`defaultColWidth = 9` |

## 字体与颜色

| 部位 | 规格 |
|---|---|
| 全表字体 | 微软雅黑（Microsoft YaHei） |
| 标题 | 16 号加粗 |
| 表头 | 11 号加粗 |
| 数据 | 10 号 |
| **单价列（J）** | 红字 `FF0000CC` + 淡蓝底 `FFF2F7FF`，格式 `#,##0.00`，**留空供供应商填** |
| **合价列（K）** | `=IF(Jn="","",Hn*Jn)`，格式 `#,##0.00` |
| 合并行标记 | 淡绿底 `E2EFDA`（形态 B 的合并行复核用） |

## 套用方式（openpyxl）

**禁止跨工作簿赋值 `cell._style`** —— 它是源工作簿的样式表索引，会 `IndexError: list index out of range`。
必须搬真实样式对象：

```python
from copy import copy
from openpyxl import load_workbook

tpl = load_workbook(TPL_PATH)
tws = tpl[tpl.sheetnames[0]]

def snap(cell):
    return dict(font=copy(cell.font), fill=copy(cell.fill), border=copy(cell.border),
                alignment=copy(cell.alignment), number_format=cell.number_format,
                protection=copy(cell.protection))

def apply(cell, s):
    cell.font = copy(s["font"]); cell.fill = copy(s["fill"])
    cell.border = copy(s["border"]); cell.alignment = copy(s["alignment"])
    cell.number_format = s["number_format"]; cell.protection = copy(s["protection"])

ST = {
    "title": snap(tws.cell(1, 1)),
    "hdr":   [snap(tws.cell(2, c)) for c in range(1, 12)],
    "dat":   [snap(tws.cell(3, c)) for c in range(1, 12)],
    "tot_a": snap(tws.cell(tws.max_row, 1)),      # 合计行 A 列
    "tot_k": snap(tws.cell(tws.max_row, 11)),     # 合计行 K 列
}
```

## 多工作表 / 多文件两种形态

同一套 `fill_sheet(ws, cat, data)` 逻辑，两种装载方式：

```python
# 多文件：每类别一个 Workbook
wb = Workbook(); ws = wb.active; ws.title = cat; fill_sheet(ws, cat, data)

# 单文件多工作表：一个 Workbook，逐类别 create_sheet
wb = Workbook(); wb.remove(wb.active)          # 去掉默认空表，避免多余 Sheet
for cat in CATS: fill_sheet(wb.create_sheet(cat), cat, data)
```

## 校验要点

- 表头 11 列**逐字**与模板一致
- `A1:K1` 与 `A{末}:H{末}` 两个合并区存在
- 标题含真实地址，**无占位符**（`＿＿`、`___` 出现即失败）
- 序号 `1..N` 连续
- 单价列全空、合价列公式为 `=IF(Jn="","",Hn*Jn)`
- 合计行 `K` 公式为 `=SUM(K3:K{末-1})`
- 多工作表形态额外校验：工作表名与顺序、每张表都带完整标题与合计行
