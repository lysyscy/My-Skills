# 形态 A：单表拆分（一张大表 → 分类多表）

## 适用与目标

输入是一张（或少数几张）工作表：R1 标题行、R2 表头行、R3 起数据，**列位齐整但多个类别混在一起**。
目标：按「名称」归入类别，拆成多张规范表（可再合并为单文件），途中完成拆列、去重、排序、套模板。

典型案例：工程设备材料询价表（工艺管道 / 设备 / 非标件清单），273 行 × 8 列。

## 1. 结构摸底要点

- 常有 `Sheet1` 有数据、`Sheet2/3` 全空的干扰 —— 先确认哪张表真有数据。
- 常见表头：`序号｜名称｜规格型号｜材质｜单位｜数量｜图号/备注｜`，**第 8 列常无表头**（内容是"投标方采购安装"这类附加说明）。
- 常见异常：**名称为空、系统名写在规格型号列**（如 `除尘系统（PC-1）`）—— 这类行的"名称"其实在规格列，须移回名称列（这是一处判断，要告知用户可撤）。
- 先查 `merged_cells.ranges` 判断是否存在"一台设备占多行"。本类大表通常**没有**合并（一行一料）；若确有合并，参考形态 B 的设备多行合并。

## 2. 建分类映射（NAME_CAT）

- 先取**去重名称全集**（案例：273 行 → 96 个名称），逐个显式归类，**不要用关键词模糊匹配**。
- 断言：`len(rows) == 源数据行数` 且 `unmatched == []`，然后打印未命中项。
- 材料类类别口径：钢材、管件、阀门、桥架、配电柜、线缆、其他、设备、仪表。
- **空类别必须问用户**：本表没有的类别（如电气类的桥架/配电柜/线缆），是跳过不生成还是生成空表等后续填？不要擅自决定 —— 并提示用户"若预期有这些内容，可能还有另一个源文件"。
- 边界归类要列给用户复核（案例：`Y型过滤器`→阀门、`水表`→仪表、`散热器`→设备、`地漏`/支吊架→管件）。改一处 `NAME_CAT` 即可重跑。

## 3. 列结构对齐（源列 → 模板列）

源表列与目标模板列常对不齐，**缺口必须问用户，不能替用户猜**：

| 模板列 | 源表来源 | 常见状态 |
|---|---|---|
| 序号 | 序号 | ✅ |
| 类别 | 新增 | 填分类名 |
| 名称 | 名称 | ✅ |
| 规格型号 | 规格型号 | 长参数需拆走 |
| 材质/牌号 | 材质 | ✅ |
| 技术参数 | 无对应列 | ⚠️ 从规格型号拆出 |
| 单位 / 数量 | 单位 / 数量 | ✅ |
| 备注 | 图号/备注 | ✅ |
| （源表第 8 列等无表头列） | 无对应列 | ⚠️ 并入备注，或新增列保留 |
| 单价 / 合价 | 新增 | 单价留空待填、合价带公式 |

## 4. 拆列：规格型号 → 技术参数

触发条件（该格是"长参数描述"）：含换行 / 含全角冒号 / 去换行后长度 ≥ 30。

**关键：整格搬移会连型号码一起搬走** —— `⌀60x10`、`JLR-L-25B`、`WEX-450D4-0.24` 会被一起搬进参数列，规格列就空了。
正确做法：**先切出"型号/规格短码"留在规格型号，其余进技术参数**。

```python
DELIMS = ["；", ";", "\n", "，", ",", " "]
# 触发后，取最靠前的分隔符切分：
#   head 判定为「型号短码」的条件：0 < len(probe) ≤ 25、不含中文、含字母或数字，且 rest 非空
#     → head 留「规格型号」，rest 进「技术参数」
#   否则 → 整格进「技术参数」
```

**恒等式断言（必加）**：

```python
_nz = lambda t: re.sub(r"[\s；;，,\n]", "", str(t))
assert _nz(spec_v) + _nz(param_v) == _nz(spec), f"R{row} 拆列丢字"
```

**同类行必须拆法一致**：两个同款排风机，一行拆出一行没拆，是 bug 不是特性。

## 5. 去重：口径选择

两档口径，**让用户选**。差别只在"哪些行算同一行"。

### 严格口径

除「数量」外各列**逐字全等**才合并；数量求和；位置取源表首次出现。
键 = `(类别, 名称, 规格型号, 材质, 技术参数, 单位, 备注)`。

### 宽松口径（在严格基础上放宽 4 处；名称、单位仍要求逐字全等）

| # | 放宽项 | 规则 | 举例 |
|---|---|---|---|
| 1 | 规格型号写法 | 去空白、全角转半角、`PN=` ≡ `PN` | `DN50,PN=1.0MPa` ≡ `DN50,PN1.0MPa` |
| 2 | 备注标点 | 去空白与顿号/逗号/分号差异 | `带角阀、表弯、及管件` ≡ `带角阀、表弯及管件` |
| 3 | 备注与材质重复 | 备注 == 材质（录入冗余）时，备注视为空 | 备注 `S30408` ≡ 空 |
| 4 | 材质空缺 / 图集号 | 标准图集号（`04S301`、`10S416`）**比较时视为空**；组内至多一种非空材质时，空材质被吸附进来 | 地漏 `DN100`：材质 空 + `04S301` → 合并 |

**保守兜底**：同一「名称+规格+技术参数+单位」下出现**多种真实材质**（如 `S30408` 与 `316L`）→ **不吸附**，按材质各自成组。

**输出取值**：合并行的 规格 / 材质 / 备注 取组内**出现次数最多的原文**（并列取首次）；技术参数随所选规格型号成对取用，避免二次拆分。

### ⚠️ 分组键必须覆盖所有"承载差异"的列

案例踩坑：宽松口径第一版**漏了「技术参数」**，把
`钢制联箱管耐腐蚀型散热器` 的 `15/20/25 片/组`（三种不同规格）和
`边墙式排风机` 的两种工况误合成一组 —— 因为它们的「规格型号」列**恰好内容相同**（散热器为空、风机都是同一个型号），差异**全在技术参数里**。

**凡"某列内容被搬到另一列"的拆列场景，拆出的两列都要进键。**

**发现方式值得记住**：不是校验脚本报的，是看输出**设备类凭空从 18 行掉到 15 行**，与常识不符才回头查。
→ **每类行数要与源表分布对账**，行数异常是比脚本报警更早的信号。

**防呆断言**：合并组内成员的「名称 / 规格型号 / 技术参数 / 单位」四要素必须完全一致，否则报错中止。

## 6. 排序（供应商阅读序）

目的：供应商打开就能顺着报价 —— 同一种料聚成连续块，块内口径由小到大。

排序键依次：**类别 → 品类逻辑序 → 规格口径升序 → 材质 → 技术参数 → 备注 → 规格原文**

### 口径解析规范（关键 —— 否则 `DN100` 会排在 `DN65` 前面）

```python
_DN = re.compile(r"DN\s*(\d+)", re.I)
_NUM = re.compile(r"\d+(?:\.\d+)?")
# 角度前缀（90E(S) / 45E(L) / 90°）与壁厚系列（Sch40）都不是"口径"，须剥掉
_ANGLE = re.compile(r"^\s*(?:45|60|90|180)\s*(?:°|度)?\s*[A-Za-z]{0,3}\s*(?:\([A-Za-z]\))?")
_SCH = re.compile(r"Sch\s*\d+", re.I)

def dim_key(spec):
    t = str(spec)
    dns = _DN.findall(t)
    if dns:
        return tuple(int(x) for x in dns)              # DN50XDN32 → (50, 32)
    t = _SCH.sub("", _ANGLE.sub("", t))
    return tuple(float(x) for x in _NUM.findall(t))    # 90E(S)100-Sch40 → (100,)
```

**必须按数值比较**，不能按字符串（字符串序会把 `DN100` 排在 `DN65` 前）。
`90E(S)100-Sch40` 里开头的 `90` 是弯头**角度**、`Sch40` 是**壁厚系列** —— 不剥掉，它就会因 90 < 100 漂到 `DN100` 前面，与同口径的料不相邻。

### 品类逻辑序（NAME_ORDER）

按现场安装 / 加工顺序排名称；未列入者排末尾（按名称串），日后新增名称不会崩。

- **钢材**：无缝钢管 → 压缩空气无缝钢管 → 不锈钢管 → 方管 → 钢板、型钢 → 钢材
- **管件**：管材 → 弯头(90°→45°) → 三通(三通→正三通→异径三通→45°斜三通→Y型三通→顺水三通) → 异径管/接头 → 附件(盲板→泄水丝堵→地漏) → 高压系统 → 支架
- **阀门**：截止阀 → 蝶阀 → 球阀 → 止回阀 → 减压/调压 → 过滤器 → 排气 → 平衡 → 温控 → 水泵控制阀 → 泄水阀 → 倒流器
- **仪表**：压力表 → 弹簧压力表 → 磁助电接点压力表 → 温度计 → 水表
- **设备**：储气罐 → 电动葫芦 → 风机 → 冷风机/冷气机 → 散热器 → 潜水泵 → 洗地机 → 系统条目
- **其他**：卫生器具 → 风管/风口 → 除尘附件 → 格栅 → 保温材料 → 标识 → 油品 → 汇总条目

### 证明"排序没动数据"

排序前/后导出的审计表逐行做**多重集比对**，连「合并行数」「源 Excel 行号」两列都要对得上 —— 只允许顺序不同。

## 7. 套模板（格式复刻）

完整规范见 `询价单模板规范.md`。核心坑：**openpyxl 不能跨工作簿赋值 `cell._style`** —— 那是源工作簿的样式表索引，会 `IndexError: list index out of range`。必须搬真实样式对象：

```python
def snap(cell):
    return dict(font=copy(cell.font), fill=copy(cell.fill), border=copy(cell.border),
                alignment=copy(cell.alignment), number_format=cell.number_format,
                protection=copy(cell.protection))

def apply(cell, s):
    cell.font = copy(s["font"]); cell.fill = copy(s["fill"])
    cell.border = copy(s["border"]); cell.alignment = copy(s["alignment"])
    cell.number_format = s["number_format"]; cell.protection = copy(s["protection"])
```

另一个坑：源表把材质 `304`/`316` 存成了**数字** `304.0`，写回时会变数值 —— 文本列须显式 `str(int(v))` 归一。

## 8. 输出形态

- **多文件**：每类别一个 `<项目>（<类别>）.xlsx`，便于按类别分发给不同供应商。
- **单文件多工作表**：所有类别放进一个文件、每类别一张 sheet，格式与分文件完全一致 —— 便于整体传递不丢件。
- 序号：**每张表内 1..N 连续**（便于报价），或沿用原序号（便于对回源表）—— 由用户定。
- 两种形态都保留时，**明确告知哪份是对外交付版本**，避免两份混用。

## 9. 校验清单（形态 A）

用独立脚本回读源文件与输出，**按表头名定位列**（不写死列号）：

1. 输出行数 == 源合并后身份数
2. **无遗漏**：源每一行都能回溯到某个输出行（靠源 Excel 行号列追溯）
3. **无捏造**：输出行的名称/材质/备注必须取自源成员原文
4. **数量总和守恒**：源 == 输出
5. 每个合并组的数量 == 组内源数量之和
6. 每个分组键在输出中只对应 1 行
7. 格式面：表头 11 列一致、序号 1..N 连续、单价全空、合价公式正确、标题含地址且无占位符、合计行合并与公式
8. **行序单调性**：每张表行序符合排序键（校验侧**独立重写**口径解析，不复用生成脚本）

⚠️ **出现成片差异时先怀疑校验脚本本身**（数字 vs 文本、空白/分隔符归一、拆列后列序变化、列号写死）。
本类任务曾连续 3 轮"校验失败"，排查后**全部是校验脚本自己的问题**。校验口径必须与生成口径**逐字一致**。

## 10. 交互经验

- **先给实测事实再提问**：把源表结构、各类行数、空分类、疑似重复组数摆出来，再问决策项。
- **一次问齐关键分叉**（输出形态 / 空分类 / 列结构 / 序号口径），批量提问比挤牙膏高效。
- 用户改主意（"合并为一个文件""再跑一轮"）时，**先把已验收版本备份并留 md5 指纹**，新版本另存，绝不覆盖。
- 扫描出的"疑似重复"要**分类呈现**（只差备注 / 只差规格写法 / 只差材质），并标注哪些建议保留不合并（如备注写的是真实工艺差异"车间外侧管道需要保温处理"）。
