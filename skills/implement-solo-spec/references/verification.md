# 专项验证与失败处理

编辑循环先跑能暴露当前缺陷的最小场景，相关分支稳定后合并共享影响及项目必需检查。只读取本次触发的分支；基础验证与最后回执由执行核心负责，不在此建立另一轮收尾。

## 高风险及共享契约

权限、资金/业务写入、事务/回滚和共享契约，从实际注册/调用清单定位所有适用入口及依赖，区分机制存在与入口确实执行保护。每类至少有独立正常预期与能暴露原缺陷的失败反馈，按风险核旧读取提交、另一设备修改、删除重建、撤销/恢复、重启及整批回滚；不适用项说明原因，不能用一个入口通过代表整类已核。风险取决于行为与影响，不由改动行数或测试数量决定。

测试应对公共行为有独立预期；不要通过私有实现的同一计算重算预期，也不要只证明一个 mock 配合另一个 mock。已有必要保护用例不能为了缩小测试集被删除或降级；修改共享调用时同时定位保护它的现有检查，原实现匹配断言确需调整时保留其缺陷检测能力，关键新断言按风险验证能否检出失败。

## 数据与环境

在启动会写入的测试前确认数据源、数据库/文件副本、端口、账号会话、输出目录及清理所有权。浏览器会话隔离不等于后端数据隔离。复制的源码、构建和数据要能对应本次目标输入；已有服务不能未经核实就当本次版本。

生产服务或真实业务数据需要独立权限，不从测试授权推导。并行运行必须避免共享可写资源；不为提速扩大到真实环境。复用项目的准备/收尾方式，保证必要日期、构建和数据可复现；独立场景应能单跑，不依赖执行顺序。

从已确认输入准备隔离副本时核源与目标的真实绝对路径；复制失败立即停止依赖它的构建或测试。接受结果前核实际工作目录、关键输入与产物来源；版本、清单或摘要不匹配的结果排除，修正后只复验受影响范围。

## 浏览器和视觉

界面变更确需浏览器时优先等待可观察状态，不用固定长 sleep 代替就绪判定。编写或优化测试时使用框架自动等待与可重试断言；超时先核定位、挂载和布局。参考须适配实际语言和执行器。只验证受影响交互和项目要求的覆盖；没有证据不默认建立完整浏览器/分辨率矩阵。

布局/视觉结果必须实际看图或界面，必要时补尺寸断言，不能只凭截图文件存在或页面结构可读声称通过。保留必要来源、环境与结果对应关系，临时截图不永久复制到多个文档。

数据量、页面、尺寸与主题按各自风险选代表场景，只有真实交互依赖才组合矩阵；共享样式、组件或契约变化扩大到受影响路径。重复动线由已有确定性测试执行，Agent 看简短结果和异常，不每次加载交互操作技能。仅在探索/诊断确有需要时选择交互能力。重资源场景可复用浏览器进程，但页面、上下文和可变数据仍隔离，不为优化耗时顺手更换可靠框架。

## 失败

把失败区分为产品问题、测试问题、环境问题或尚未确定。保留实际命令、非零退出、超时、错误信息及相关输入，先收窄归因再重试。不改预期、跳过测试、替换数据口径或降低门槛来换绿灯。

步骤、进程、重试与清理要有界；未知选择、异常和断言失败返回非零。挂起先诊断期限与环境，不反复修改产品；保留首次失败输出及必要截图/轨迹，禁止用静默重试隐藏首次失败。工具建议的自动修复仍需对照真实规格和缺陷。

确认与本次无关的既有失败时，保留其非零证据与已有/必要的问题指针，按项目真实阻塞规则处理；未确认的失败不能直接归为旧问题，也不能把有无关非零结果的整个入口报成全绿。仅重跑定位/修复所需范围，但输入变化使旧证据失效时必须补验。

## 证据和清理

结果绑定代码/资料版本、验证输入、环境与覆盖范围，包括影响预期或选集的票与规则。任何一项影响判定的变化都使相应证据失效；最终资料同步后核一次最终输入。执行器只支持整组失效时按其真实能力处理，人工解释未变不等于实现了逐用例缓存。

清理只针对本轮拥有且不再需要的现场；未知、共享、仍有恢复/失败定位价值的资料保留。
